GTA SA Mobile 2.11 Source / SAMP

This repository contains a leaked copy of a GTA SA Mobile 2.11-based project that I worked on.

Important

- Many bugs, crashes, and issues are still present.

About

I contributed to the development of this project, including Android storage path changes, bug fixes, project maintenance, and various modifications. The source was later distributed publicly without my authorization.

Since copies are already circulating publicly, I am publishing this repository to preserve the project's history and ensure contributors receive proper credit.
